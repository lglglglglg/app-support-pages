常见问题

“准备”“今天”“将来”如何区分？

没有安排日期的任务进入“准备”；今天及更早、仍未完成的任务显示在“今天”；明天及以后的任务显示在“将来”。提醒到点不会自动完成任务，只有你手动标记完成才进入“已完成”。

为什么没有收到提醒？

请先在 iOS“设置 → 通知 → 19任务”检查权限、声音与锁屏展示，再查看专注模式和通知摘要。App 内“我的 → 通知与隐私”可查看安排状态、发送测试通知，并尝试“检查并修复提醒”。这些状态表示系统是否接受了提醒请求，实际展示仍由 iOS 控制。

“强提醒”和普通提醒有什么区别？

普通提醒使用系统通知。iOS 26 及以上可对单个任务主动开启实验性的系统闹钟式强提醒；它需要单独授权，停止闹钟也不会自动完成任务。强提醒不可用时，App 会尝试退回普通通知。

怎样备份或恢复任务？

在“我的 → 数据与备份”导出 JSON 完整备份，妥善保存文件。恢复会替换当前全部任务，请先确认备份内容；CSV 是便于阅读的表格导出，不用于完整恢复。文件只在你主动选择分享目标后交给外部应用。

如何添加桌面小组件？

安装包含小组件的版本后，先打开一次 19任务，再长按主屏幕空白处添加小组件，搜索“19任务”。可选择今天数量、今天前三项和下一条提醒。标题与时间可能显示在桌面上；iOS 决定具体刷新时机。旧版安装包可能尚不包含小组件。
