隐私政策

生效日期：2026 年 11 月 2 日 · English

本政策适用于 SHIJIU STUDIO 的 VerseName iPhone 应用当前版本。

1. 本机保存与数据收集

命名项目、姓氏或前缀、筛选偏好、收藏、短名单、决选结果、主题和试读声音偏好保存在设备上的应用数据中。旧版试读笔记可能仍留在既有项目里，可在设置中主动清除。当前 App 不要求注册账号，不集成广告、第三方分析或开发者自建同步服务器，也不自动将这些内容发送给我们。

2. 来源链接、语音与分享

候选与来源材料随 App 提供，可离线查看。你主动点击古籍出处链接时会打开外部网站；该网站可能按自身政策处理访问数据。试读使用 iOS 系统语音资源；App 不请求麦克风权限、不录音。你主动使用系统分享时，所选文字或图片卡会交给你选择的目标应用，由其按自身规则处理。

3. 项目备份

只有你主动导出时，App 才通过 iOS 文件界面生成 JSON 项目备份。备份包含项目中的姓氏、偏好、收藏和决选信息，可能包含旧版试读笔记；文件未加密，请选择可信的位置保存。导入时 App 从你选定的文件读取内容并加入本机项目；相同项目 ID 会另存为副本。若你把备份放在 iCloud Drive 或其他文件服务，该服务按自己的政策处理文件，App 不提供自动同步。

4. 保留与删除

你可以在 App 中删除命名项目、清除旧版试读笔记。删除 App 会移除其设备应用数据；“卸载 App”及 iOS 系统备份的保留行为取决于系统设置。已经导出到“文件”或其他位置的备份需在该位置自行删除。

5. 支持网页与联系

支持网页托管在 GitHub Pages，访问网页时 GitHub 可能处理网站访问数据；打开网页不代表 App 自动上传命名项目。你主动发送支持邮件或加入 QQ 群时，相应邮件或社交服务会处理你选择提交的信息。隐私问题请联系 shijiuhan19@gmail.com。

6. 政策更新

如未来加入账号、联网生成、分析、内购或其他改变数据处理方式的功能，我们会在发布前更新本政策及对应的 App Store 隐私申报。

VerseName Privacy Policy

Effective November 2, 2026

1. On-device data

VerseName stores naming projects, surnames or prefixes, preferences, favorites, shortlists, comparisons, appearance and speech voice settings in the app's on-device data. Notes from an older version may remain in existing projects and can be removed in Settings. The current app requires no account and includes no advertising, third-party analytics, or developer-operated sync server. It does not automatically send these project details to us.

2. External links, speech, and sharing

Name and source materials are bundled for offline reading. If you open a classical source link, the external site may process your visit under its own policy. Read-aloud uses iOS system speech; the app does not request microphone access or record audio. If you share text or a name card, the destination you choose receives that content under its own rules.

3. Backups

Only when you choose Export does the app create a plain, unencrypted JSON backup through the iOS file interface. It contains project details and may include older read-aloud notes. Import reads a file you select and adds projects locally, creating copies when IDs collide. If you store a backup in iCloud Drive or another file provider, that provider handles the file under its policy; VerseName does not automatically sync it.

4. Retention and deletion

You can delete projects and clear old notes in the app. Deleting the app removes its device app data. Offloading and system backups follow your iOS settings. Backups exported elsewhere must be deleted in their saved location.

5. Support and updates

This support site is hosted on GitHub Pages, which may process website visits. Opening it does not upload app projects. Email and QQ services process information you choose to submit when contacting us. For privacy questions, email shijiuhan19@gmail.com. We will update this policy and App Store privacy answers before releasing features that change data handling.
